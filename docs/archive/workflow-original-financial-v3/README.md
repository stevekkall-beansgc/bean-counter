# Historical original-financial DATA prototype

These byte-exact source blobs preserve the disconnected, incomplete Operation3 /
Authority2 reconstruction prototype. They had no runtime caller and did not
establish a completed original audit. This archive is not an available endpoint.
The provenance file pins their source commit and SHA256 bytes.

The three useful helper compatibility tests remain in the private test-only
`legacy_original_compatibility` module. Shared raw draft/replay validators,
Operation9 reconstruction, financial observation child modules and the current
local original/status/retry verifier remain compiled and unchanged by this move.
Broader explicit audit/rebuild remains required work; this archive does not claim
that obligation complete or erase the frozen original contracts.
