# Legacy workflow semantic regression applicability

Owner-approved QA clarification, 2026-10-20. This applies only to candidate
workflow semantic tests, not production admission or resource qualification.

The frozen R2 foundation contract remains unchanged. Its public raw-DATA draft
and replay profile retains the 65,536 semantic-work ceiling, and the private
finite diagnostic retains its 262,144 stop and diagnostic-storage containment.
The operator-configured local financial profile is a separate route. No new
production capability or resource-completion guarantee follows from these tests.

For the three legacy positive regressions (first Work complete golden bodies,
original birth/operation association, and independent complete-body comparison),
a private `cfg(test)` semantic domain may select an optional work limit. `None`
means no artificial semantic stop for that test, not a guessed larger cap. It
executes the same raw-record engine, validators, charged callbacks, checked
counters, draft projection and replay comparison. It adds no committed-record
trust, arena, admission owner or committable result. Existing body, numeric and
format guards and ordinary test-process cancellation/timeout remain applicable.

This is a narrow applicability amendment to the R2 section 5 rule that test
limits may only be smaller: the uncapped semantic regression is outside that
profile's resource qualification. Frozen inputs and independent output bytes
remain mandatory. A completed semantic run supplies deterministic exact-N and
N-minus-one accounting tests without a budget search. Separate tests preserve
public-limit refusal and finite diagnostic containment. Neither passing group
establishes the frozen R2 sections 5/6 foundation exit or a legacy resource fit.
