# ADR 018: Closed-stage-correction

Status: accepted for v0; implementation evidence remains gated.

Decision: Full closure reversal; no reopen, partial or compound replacement.

Consequence: Replacement touching closed stage needs newly authorized chain/stage and new invocation.

Validation: reversal oracle and later closure tests.

Authority: detailed design §27. Changing this decision requires an explicit amendment and review of affected fixtures; unimplemented behavior is not an exception.
