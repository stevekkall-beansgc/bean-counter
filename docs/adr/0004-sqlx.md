# ADR 004: SQLx

Status: accepted for v0; implementation evidence remains gated.

Decision: Concrete SQLx adapters are accepted subject to the driver gate.

Consequence: Separate SQL/migrations; no Any; fallback requires a reviewed driver ADR. Exact versions unresolved.

Validation: tracked begin, cancellation, SQLite provenance, TLS.

Authority: detailed design §27. Changing this decision requires an explicit amendment and review of affected fixtures; unimplemented behavior is not an exception.
