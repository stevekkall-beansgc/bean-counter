# ADR 012: Cost-operation

Status: accepted for v0; implementation evidence remains gated.

Decision: Native archives primary; no mandatory hosted infrastructure or runtime model.

Consequence: Optional npm/signing; users own real production operation and storage.

Validation: offline runtime and clean installation gates.

Authority: detailed design §27. Changing this decision requires an explicit amendment and review of affected fixtures; unimplemented behavior is not an exception.
