# Adoption trial observer record

Copy this template into private observation records for each participant. Keep human and supplementary agent records separate. This is an observer form, not participant instructions; supply only the [participant task sheet](participant-adoption-tasks.md), starting link and required release metadata to the participant. Use the [release-specific observer packet](beana-adoption-packet.md) for expectations and exact published identities.

An empty form is preparation, not evidence. Default every case to `unrun`; use `passed` or `failed` only after observation. A partial journey does not pass unfinished cases. Preserve failed attempts when repeating after a fix.

Before observing an agent, confirm a dedicated, user-started Bean Counter executor on a named supported platform with package acquisition/installation access, Python verification and the assigned caller runtime. Verify its access to a fresh supported environment; do not reuse another product's task. Do not start a clock during an unavailable-executor check. Do not provide prior observer answers or author trial history to an unfamiliar agent.
