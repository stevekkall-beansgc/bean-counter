# Bean Counter v0.2.2 — current public status

This documentation-only patch makes the supported local SQLite profile and phase status easy to find. Reduced Phase 4 and finance CSV Phase 5 are complete; amended local Phase 6 is complete with owner acceptance. The owner waived its separate independent-review requirement. No independent technical review was completed or passed, and the original full-platform plan remains outside this closure.

The new [status page](../STATUS.md) and refreshed requirements, compatibility, phase-gate, contributor and release docs distinguish current support from historical plans. They correct obsolete pre-publication version and CI language. The supported native artifact remains the unsigned [v0.2.1 Apple-silicon macOS release](https://github.com/stevekkall-beansgc/bean-counter/releases/tag/v0.2.1); Rust workspace package and local billing contract versions remain 0.2.1 and `v0.2`. This tag changes documentation only and does not replace the v0.2.1 native assets.

One customer and agreement per private SQLite installation, admission ceilings, operator-owned resources and all existing billing guards remain. PostgreSQL product support, multi-host use, hosting, remote authentication, payments, resource guarantees and untested platforms remain deferred. No runtime code, schema, economics, service or SDK changed.
