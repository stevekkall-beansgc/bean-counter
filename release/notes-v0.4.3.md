# Bean Counter v0.4.3 — billing roadmap and M1 evidence

This documentation-only patch publishes the owner-approved billing roadmap and the M1 current-format qualification record. M0 and M1 are complete; M2 policy is approved, but M2 implementation has not started.

M1 evidence is limited to the source-built v0.3.0→v0.4.0 ordinary local SQLite schema-8 path. The release adds no billing implementation, economic behavior, storage format or native binaries. The v0.3.0 native-package release remains the latest native distribution. Future production formats must pass the documented version/refusal/migration/recovery gate before accepting writes.
