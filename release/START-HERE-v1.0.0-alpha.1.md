This package is a testing prerelease candidate. It is not stable 1.0, is not a production-readiness or migration recommendation, and is not a published release merely because an archive exists. Confirm exact source, checksums and qualification with the matching release record if one is eventually published. Existing published v0.11.0 instructions and artifacts remain version-matched to that release.

Use a fresh private synthetic directory and a verified, version-matched executable and helpers. The bundled integration example requires `ledger 1.0.0-alpha.1 (local development)`. The reference documentation in this package may describe the published v0.11.0 baseline; it does not by itself qualify this candidate. See [candidate notes](notes-v1.0.0-alpha.1.md) for the currently known scope and gaps and the [manual-credit tester guide](../docs/manual-credit-alpha.md) for its bounded request shapes.

The local owner controls installation authority. Enrolled-source scoped reads, automatic Stage quantity correction, manual-credit retry/conflict and competing-presentation behavior are not qualified here. No payment, invoice, hosted identity or multi-host guarantee is provided. Back up the entire quiescent installation before any upgrade. Schema 21 cannot be read by the older v0.11 executable; never use an older writer or reader against an upgraded installation. An unknown commit result is not proof of rollback: preserve the original request and reconcile its status.

For a native archive, obtain `scripts/verify-native-package.py` separately from an independently trusted checkout of the exact candidate source commit. Run that verifier with the archive, matching SHA256SUMS, exact source commit, `--version 1.0.0-alpha.1` and target before extraction. Use the platform installer from that same trusted checkout with the archive, SHA256SUMS, source commit and a new private installation directory. To verify or install a historical v0.11.0 archive with these tools, explicitly pass `--version 0.11.0`; never substitute one release's checksum or commit for another's. No separately distributed verifier or archive is claimed to exist yet.
