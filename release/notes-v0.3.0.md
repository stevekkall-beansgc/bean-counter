# Bean Counter 0.3.0 — guided local setup

This minor release adds `ledger billing setup DIR`, a terminal wizard that gathers explicit customer and agreement terms, exact fixed USD price, outcome windows, retained assent evidence, and operator authority/finality attestations without a prepared JSON file. It validates and summarizes the terms before requiring `CREATE`, retains a private setup file, and leaves cancelled, invalid or existing paths uninitialized. The existing `billing init DIR --setup FILE --json` and strict JSON event interface remain available for unattended products and agents.

Unsigned native packages are provided for Apple-silicon macOS and Linux x86-64. The tested environments are macOS 26.6.2 arm64 and Ubuntu 24.04.5 x86-64 with glibc 2.39. The Linux binary is dynamically linked. Other macOS versions and Linux distributions are unverified; Windows, production-host certification, signing/notarization, PostgreSQL product support, multi-host operation, remote authentication, resource guarantees, hosting and payment execution remain deferred. The synthetic setup and event fixtures are demonstrations, not actual customer assent, authority, or verified model outcomes.

The local SQLite billing and finance CSV contracts remain `v0.2`; Rust workspace packages are 0.3.0. The reduced local Phase 4, Phase 5 and amended local Phase 6 are complete with owner acceptance. The owner waived the separate Phase 6 independent-review requirement; no independent technical review was completed or passed. See [status](../STATUS.md), [installation and integration](../examples/integration/README.md), [billing quickstart](../docs/billing-quickstart.md), and [recovery](../docs/billing-recovery.md). Existing release tags and assets are unchanged.
