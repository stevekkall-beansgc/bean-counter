## 1. Closed shapes, interpretation and invariants

`economic-boundary.schema.json` is a standalone Draft202012 schema. Its reachable historical definitions are copied solely to make the candidate independently readable; its root union admits only this packet's economic requests/records/reads/receipts/descriptors. Named sets sort by key; generic Ref sets and other object sets sort by JCS bytes; operation request arrays `dependent_reversals` sort by decision Ref then revision.
