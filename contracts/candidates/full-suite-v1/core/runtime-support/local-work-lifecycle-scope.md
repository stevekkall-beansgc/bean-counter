# Additive local Work lifecycle grammar

local-work-lifecycle/1 inherits exact scalar predicates, declared unit ratios, original event source/per-component funding mode and direct/declared family paths. It adds original Work status and the existing typed Reference grammar under fixed authenticated per-kind relationships, plus failed completion/no-price finality. All old descriptor assets/getters remain unchanged. Metadata alone neither admits Reference relationships nor proves any financial/original operation.

Failed completion is a permanent zero-price claim with no Target/family/app promise; an eligible original quantity may still have authorized zero-action correction and ordinary terminal reversal without changing failed status. Current caller role is separate from original worker business namespace and immutable event source.

Invocation/stage, broader component modes and same-principal financial-role delivery remain required sequential Wave2b work. They stay explicitly excluded by this increment until exact dictionaries/current-original inputs and consumers are frozen. This is not full Wave2b, runtime, native, resource or release qualification.
