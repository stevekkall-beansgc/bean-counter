## Original timing cases

Process timing_cases by overlaying each patch onto timing_base. These are conditional arithmetic/lifecycle checks, not admitted records. Let W=work_accepted_at, F=finalize_within_us, C=correction_within_us, T0=initial_cost_accepted_at or null. Compute finalize_by=W+F and prework_correction_maximum=W+F+C for every structurally valid input. The duration-zero cases are conditional arithmetic, not a new profile admission claim.

Output each {disposition,finalize_by,initial_cost_accepted_at,correction_until,prework_correction_maximum}, times six-digit UTC. Other cases disposition refused. These disposition words describe conditional results, not new operation/status wire enums. After an accepted finalize, report the computed new anchor; no output ever changes prework maximum.
