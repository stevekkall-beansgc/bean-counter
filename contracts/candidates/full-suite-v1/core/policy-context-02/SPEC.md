# Original event operational operands

This additive interpretation uses the existing Policy4 `FieldRef.context` literals `source` and `funding_mode`, existing Predicate grammar and Plan8/evaluator. It implements the owner's approved operand disposition of 2026-10-26. LocalPolicySemantics1/descriptor b449d773…7015d and every older defining artifact retain their original bytes and gates. The code-owned LocalPolicySemantics2 descriptor selects this meaning; a known older descriptor never implies the new capability.

`context.source` is the exact source of the original authenticated event OperationKey: original Work key for ordinary Work rules, original Outcome key for an Outcome expression. It is not the authenticated local operator's configured administrative source, an issuer's source, a predecessor's source, current corrector source or an inferred namespace. The event's operation key and its source authority are authenticated separately under the existing receipt/grant/custody checks.

`context.funding_mode` is derived separately for the actual rule/component being evaluated. Resolve that component's accepted binding slot and its exact accepted funding-leg name, then take that leg's immutable `mode`. A family expression uses the original target component's accepted slot and leg. Do not use the first funding leg, the current requestor's funding, a different component or an ancestor's leg. The existing closed funding-mode vocabulary is unchanged; comparing a mode does not enable an unsupported funding execution profile.

Corrections, reversals, current Evaluation validation, original STATUS/retry and restored recovery preserve these original values. Repricing with corrected facts never substitutes the correction event's source or present-day funding terms. Every producer/consumer uses the same per-instruction operands and explanation/slot dependency; literal normalization, three-valued truth, implication/exposure and unit conversion remain the same evaluator semantics.

Same-principal independent evidence issuers use the separate exact local-source-participants-01 management encoding and original/current authority rules. Their source is not substituted for the subject Work's original source. No alias, remote delivery authentication, new principal, funding mode, monetary right, payload/record version, admission limit or resource guarantee is introduced. Stage-close T is covered by its separate lifecycle packet; this descriptor does not advertise completed stages.
