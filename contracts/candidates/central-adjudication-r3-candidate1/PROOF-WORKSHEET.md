Every resource vector has six separate dimensions: canonical bytes, newly trusted

## Finite finish witness

For every admitted prefix, the obligations are the set of distinct unspent slots
owned by current grants/tokens/rounds. Finishing uses no new grant, activation
prerequisite, optional round or capacity extension:

1. Supply exact retained claims for undelivered tokens; directly commit unused
   tombstones from each pre-issuance local grant, or retain existing receipts.
2. Import original receipts before their aliases, independent of allocation order.
   Reconcile each token and local grant using exact historical source proofs.
3. Advance allocation positions one at a time and original receipt positions
   separately. A returned token has no fictitious receipt position.
4. Complete local seal folds over the fixed fenced prefix. Each page and source
   object read has a bounded resource lane; partial hash state is never complete
   coverage. Actual H includes above-cutoff nonordinary receipts.
5. Drain every selected gateway, READY, atomic bounded CLOSE, then separate local
   terminal installation and central acknowledgment. Pending acknowledgments retain
   their original owner slots. FINISH_ONLY ABORT refuses.

Each successful mandatory step consumes an existing one-time slot; exact retries
consume none. New optional admissions are excluded from this finite measure.
Fair scheduling and eventual required storage/gateway/authority availability are
assumptions; the model does not promise progress after lost authoritative data or
permanent authority revocation. Cancellable rounds purchase disjoint terminal
branches and cannot consume a protected successful-close owner.
